# Requisiti dell'editor

## Interfaccia in italiano
L'utente modifica campi leggibili, non JSON.

## Sezioni obbligatorie
- Scenario
- Regole del mondo
- Stile narrativo
- Contenuti
- Nota dell'autore
- Personaggio utente
- Personaggi
- Lore
- Stato del mondo
- Cronologia

## Funzioni obbligatorie
- Salva
- Annulla
- Anteprima modifiche
- Cronologia versioni
- Ripristina versione
- Esporta
- Importa
- Ricerca
- Modalità avanzata opzionale

## Limiti editoriali
Qualunque impostazione relativa a:
- linguaggio;
- violenza;
- erotismo adulto consensuale;
- intensità descrittiva;
- temi oscuri;
- ritmo;
- tono;
deve essere visibile e modificabile.

Il software non deve aggiungere restrizioni nascoste.

## Modifiche di grande impatto
Per modifiche come distruzione di un villaggio:
1. mostrare conseguenze previste;
2. creare backup;
3. richiedere conferma;
4. applicare modifiche coerenti;
5. preservare cronologia e ricordi.
