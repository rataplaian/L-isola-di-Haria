# Specifica di prodotto

## Visione
Haria Engine è un motore locale per mondi narrativi persistenti. Haria è il primo mondo, ma il software deve supportare altre Bibbie.

## Esperienza utente
L'utente apre il programma e vede una schermata simile a un chatbot o libro interattivo.

Barra laterale prevista:

- Gioca
- Scenario
- Personaggio utente
- Personaggi
- Lore
- Regole
- Stile e contenuti
- Nota dell'autore
- Stato del mondo
- Cronologia
- Salvataggi
- Impostazioni AI

## Principi
- Tutti i testi modificabili devono essere leggibili in italiano.
- L'utente non deve modificare JSON manualmente.
- Il sistema deve funzionare senza intervento dietro le quinte.
- L'utente può intervenire volontariamente e cambiare scenario, lore, regole o stato.
- Ogni modifica manuale crea una versione recuperabile.
- Nessuna restrizione editoriale deve essere nascosta nel codice.
- I limiti esterni del modello scelto devono essere indicati separatamente.

## Requisito centrale
Autonomia completa durante il gioco; modificabilità completa quando l'autore decide di intervenire.

## Non-obiettivi iniziali
- grafica 3D;
- voce;
- multiplayer;
- generazione immagini in tempo reale;
- simulazione economica complessa;
- addestramento di un LLM da zero.
